# 🔐 Cybersecurity Lab Setup – Week 1 | Networkwalks Internship

## 📌 Introduction

As part of my Cybersecurity Internship at Networkwalks, I started working on setting up my own cybersecurity lab environment using Oracle VirtualBox and Kali Linux.

The main objective of this task was to prepare a virtual environment where I can explore Linux, understand networking configurations, and perform practical cybersecurity exercises.

This was my first step towards gaining hands-on experience with cybersecurity tools and lab environments.

## 🎯 Objectives

- Install and set up 7-Zip.
- Install Oracle VirtualBox.
- Download and extract Kali Linux.
- Import and start Kali Linux in VirtualBox.
- Explore the Kali Linux desktop and file system.
- Understand virtual network adapter settings.
- Explore NAT Network and Host-Only Network configurations.
- Verify internet connectivity in Kali Linux.

## 💻 System Configuration

| Component | Details |
|---|---|
| Host Operating System | Windows 11 |
| RAM | 16 GB |
| Available Storage | More than 50 GB |
| Virtualization Software | Oracle VirtualBox |
| Guest Operating System | Kali Linux |
| Archive Utility | 7-Zip |

## ⚙️ Implementation Steps

### 1. Installing the Required Software

I installed 7-Zip to extract the Kali Linux archive and Oracle VirtualBox to create and manage my virtual machine.

### 2. Downloading and Setting Up Kali Linux

I downloaded the Kali Linux VirtualBox image from the official Kali Linux website and extracted the downloaded archive using 7-Zip.

### 3. Importing Kali Linux into VirtualBox

I added the Kali Linux virtual machine to Oracle VirtualBox. During this process, I encountered a duplicate UUID error because the VM was already registered. I resolved the issue and continued with the existing virtual machine.

### 4. Starting Kali Linux

I started the Kali Linux virtual machine and successfully logged in to the operating system.

### 5. Exploring the Kali Linux Environment

After logging in, I explored the desktop environment and used the File Manager to understand the Linux directory structure and available files.

### 6. Understanding Network Configuration

I explored the network settings of the Kali Linux virtual machine, including the available virtual network adapters (Adapters 1–4).

I also explored NAT Network and Host-Only Network settings in Oracle VirtualBox to understand different virtual networking modes.

### 7. Internet Connectivity

I successfully accessed the internet from my Kali Linux virtual machine and verified that network connectivity was working.
